## 正文（约 2000 字，可直接粘贴）

上周我给自己派了个任务：**让 AI Agent 把同一篇技术稿发布到 8 个内容平台**——掘金、知乎、CSDN、头条、B站、简书、51CTO、开源中国。

每个平台的编辑器都不一样：掘金是 CodeMirror，知乎是 Draft.js，CSDN 是 CKEditor 加一个 Markdown 导入器，51CTO 的发布弹窗里分类是单选 radio 组。再加上登录态、验证码、审核流程——这个任务基本把"Agent 操作网页"的所有难点凑齐了。

下面是完整记录，包括失败的部分。

## 一、任务拆解

先定义什么叫"发布成功"。我的判据只有一条：**公开页面能读到正文，且刷新后还在**。toast 弹窗、"发布成功"页面一律不算数——掘金的 `/published` 会回落首页，CSDN 的成功页也只是 URL 跳转，都不能当证据。

8 个平台的真实结果：

| 平台 | 编辑器/发布链路 | 结果 |
|---|---|---|
| 掘金 | CodeMirror + 弹窗 | ✅ 2 篇，第二篇挂「AI 编程」话题 |
| 知乎 | Draft.js（文章+回答） | ✅ 2 篇 |
| CSDN | CKEditor + MD 导入 | ✅ 2 篇 |
| 头条 | ProseMirror | ✅ 过审 |
| B站 | 跨进程 iframe 编辑器 | ✅ 视频+专栏 |
| 简书 | contenteditable | ✅ |
| 51CTO | 单选分类弹窗 | ✅ 过审（人工审核） |
| 开源中国 | Tiptap ProseMirror | ✅ 过审（自动审核误判→人工复审通过） |

## 二、三个最贵的坑

**坑 1：Cmd+V 不触发原生粘贴。**
通过 CDP 派发合成键盘事件，是直达渲染器的，不过浏览器进程的加速键路径——所以在普通 input 里能粘贴，到了 Draft.js 里格式全丢。解法是合成 `ClipboardEvent` + `DataTransfer(text/html)` 派发 paste，让编辑器自己过粘贴管线。知乎那篇的 6 个 h2、48 个加粗 span 就是这么保住的。

**坑 2：工具返回 success，但页面上什么都没发生。**
这是最危险的一类故障：Agent 信了，继续往下走，错误在第三步之后才暴露。所以"操作生效了没有"必须是工具原语，不是事后自查——快照前后对比，返回显式的 changed/unchanged 判定 + JSON path。靠这个拦下了至少三次"以为填进去了其实没有"。

**坑 3：语义树里有两个 editable，第一个是搜索框。**
知乎的页面里，顶部搜索框和正文编辑器都带 `editable` 状态。按 `editable` 过滤会先抓到搜索框——第一次粘贴就粘进去了，靠字数校验才拦住没提交。定位必须按 `role === 'textbox'` + `editable=richtext` 双重过滤。

## 三、这套东西怎么工作的

不截图、不 OCR。页面在 Agent 眼里长这样：

```json
{
  "role": "textbox",
  "label": "请输入文章标题（5～100 个字）",
  "value": "",
  "states": ["visible", "focused"],
  "actions": ["type", "clear", "focus"]
}
```

带类型、带标签、带稳定 ID。点击和输入走 CDP 受信事件，Draft.js / ProseMirror / Quill / CKEditor 是同一条通道，不需要任何网站特判。

窗口是你桌面上那个常驻的 Electron 浏览器，登录态持久。遇到滑块、扫码、支付确认，人直接动鼠标接管，Agent 在对话里等着就行——没有交接 API，也没有权限弹窗。

canvas 类应用（比如 Excalidraw 白板）在 DOM 层是空的，但 2D canvas 的文字是在 `ctx.fillText()` 里画出来的，在绘制调用层直接截字符串，字体、坐标、颜色全在，零 OCR。

## 四、发布之后的数据（不修饰）

跑完这只是前半场。这些稿子发出去之后一周的真实数据：

- 掘金第二篇（挂话题）：1264 展现 / 31 阅读 / 1 赞——**分发给了量，但 CTR 只有 2.5%，接不住**
- CSDN 第二篇：184 阅读 / 21 收藏 / 18 赞——发布 22 小时，收藏率 11%
- 知乎回答：0 赞同——落点问题只有 429 浏览，选错了战场
- B站视频：15 播放 / 2 赞
- GitHub：14 天 48 次浏览，**外部 referrers 0**

最后一条最难堪但最值得说：**内容发出去了，没有一个平台给仓库带来点击。** CTA 的形式有问题，这是下一轮要修的事。工具能解决"怎么发"，解决不了"发了有没有用"。

## 五、边界（如实说）

- macOS / Linux 已测，Windows 没测
- 首次启动要拉约 110MB 的 Electron 引擎，国内可以设 `ELECTRON_MIRROR` 镜像
- 控制端口只绑 127.0.0.1 且没有鉴权，**不要转发这个端口**
- 51CTO 有人工审核，OSChina 的自动审核会把"滑块/验证码"相关词误判为违规，要留审核余量
