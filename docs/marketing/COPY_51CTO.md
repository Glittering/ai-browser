# 51CTO 成稿（实践向 · 约 1400 字）

**标题：** 不用截图也能让 Agent 操作网页：语义树方案的一次落地实践

**标签建议：** AI Agent、浏览器自动化、MCP

**正文：**

## 一、起因：脚本最贵的不是写，是每次重新登录

我有一个每周重复的工作：把一篇技术稿发到五六个内容平台。脚本本身不难，难的是每个平台都要登录——短信验证码、扫码、滑块。Playwright 脚本每次起一个全新的浏览器实例，登录态不共享，于是每周都要人肉重复一遍验证流程，脚本省下的时间全搭进去了。

我把方案换成"复用我日常登录的浏览器"之后，问题从"登录"变成了另一个：Agent 怎么在真实网页上又准又稳地操作，而且我能随时看见它在干什么。

## 二、方案盘点：四种主流路线各卡在哪

- **截图流**（Ask、Computer Use 一类）：每一步烧一次视觉 token，滚动页面后坐标全废；toast 提示一闪而过，截图根本来不及。
- **Playwright MCP**：结构化能力没问题，但实例是临时的，登录态不共享；对 Draft.js、ProseMirror 这类富文本编辑器，合成事件打不进去。
- **chrome-devtools-mcp**：驱动的是调试端口上的浏览器，能用已登录的 profile，但调试端口和用户日常使用容易互相干扰。
- **Browser-use**：给了 DOM 给了坐标，但对"canvas 上没有 DOM"的场景无能为力。

共同断点其实只有一个：**身份**。自动化真正的失败不在"不会点按钮"，而在登录态、扫码、2FA、支付确认——这些环节人必须在回路里，但要能随时接手。

## 三、落地路径：四步

我最终用 Electron 做了个常驻浏览器 ai-browser，走四步：

1. **常驻窗口代替临时实例**。就是你日常在用的那个浏览器，登录态天然共享。Agent 操作时你能看到每一步；遇到扫码和滑块，你伸手拿鼠标接管，它在对话里等着。
2. **语义树代替截图**。页面转成一棵带角色、标签、值、状态、可执行动作的树，每个元素有稳定 ID，附带 context（弹窗、必填提示、成功消息、登录态）。
3. **CDP 受信输入代替合成事件**。通过 CDP 发受信键鼠事件，Draft.js、ProseMirror、Quill、CKEditor 全都不用单独适配——它们本来就是给真人键鼠用的。
4. **显式验证代替盲信返回值**。每个动作返回 changed/unchanged 判定，带前后值和变更路径，对页面数据模型做指纹。连"只改 canvas 数据、DOM 零变动"的操作也能抓住。

## 四、三个真实踩坑

**坑 1：CMD+V 需要修饰键时序。** 现象：粘贴 Markdown 到富文本编辑器，纯文本进了但格式丢了。排查：合成 paste 事件没有 trustworthy 标记，Draft.js 直接忽略。结论：必须走 CDP 按下 Cmd → V → 抬起 的真实时序。解法：把 press 动作支持修饰键组合封装成原语。

**坑 2：Promise 没等到 resolve。** 现象：evaluate 里调了页面函数，返回值永远是 undefined。排查：页面函数是异步的。结论：evaluate 必须支持 awaitPromise。解法：包一层 Promise 再序列化返回。

**坑 3：el-autocomplete 不吃合成 click。** 现象：掘金发文章挂标签，程序化 click() 后下拉列表不出现。排查：Element Plus 的 autocomplete 监听的是受信 focus/input。结论：合成事件在所有主流 UI 库里都不可靠。解法：用 CDP press ArrowDown + Enter 做受信选中。

## 五、实测结果

- 知乎（Draft.js）：登录态复用，回答创建、正文写入、提交，全流程通。
- CSDN（CKEditor）：同上。
- 东方财富行情页：语义树单次 2458 节点，含全部行情单元格文本。
- Excalidraw（纯 canvas）：写字后从 2D 绘制调用层直接读回文字与坐标，零 OCR、零截图。

## 六、边界与风险

- 只在 macOS 和 Linux 测过，Windows 未测。
- 首次启动拉约 110MB 引擎数据。
- 控制端口只绑 localhost 且无鉴权——**别把它转发到外网**。
- canvas 读取需要 `AI_BROWSER_CANVAS_HOOK=1` 显式开启。

## 七、小结

让 Agent 操作真实网页，关键不是更强的视觉模型，而是给它结构化的信息、真实的输入通道、显式的验证，再把"人在回路"设计进去。项目 MIT 开源：https://github.com/Glittering/ai-browser ，一条命令可试：`npx -y @glittering0717/ai-browser mcp`。跑不通欢迎把日志贴到 Discussions。
