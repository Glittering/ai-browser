# AI 装了这个浏览器工具，从"啥也打不开"变成"啥都会干"

你家的 AI 助手是不是也这样？

让它去知乎写篇文章，它卡在登录页出不来；让它去后台发布，它看不懂弹窗；让它读个金融网站，它光截图不干活。

不是你不会用，是**没给它配一把好用的"手和眼睛"**。

最近发现一个神级小工具，**装完 AI 直接开挂** 🚀

就是 🌟 **AI Browser**（`Glittering/ai-browser`）

## 🔥 它牛在哪？一个字，真。

别人的 Agent 是"截图 + 猜"。截张图，用 AI 认字，认完还要猜坐标去点。网页一动，全白搭。

**AI Browser 反过来：直接读网页的"源代码"——语义树。**

就像把网页的地图直接递给 AI，每个按钮、输入框都有编号，点哪个、输入啥，清清楚楚，根本不靠猜。

## ✅ 富文本编辑器，直接打通

（这可是截图方案的死穴！）

官方实测知乎的 Draft.js 编辑器：标题 → 多段落 → 加粗 → 清空 → 发布，**全流程无痛**。连知乎屏蔽的"全选快捷键"它都能自动补救，**不用给任何编辑器单独适配**。

## ✅ 兼容所有主流 Agent

Claude、Cursor、Codex……它是标准 MCP，装一次全部能用。

## ✅ 登录状态帮你保存

不用三分钟掉一次登录。

## ✅ 还能查网络返回

403/404/500 一眼看穿。

## 📦 安装就 3 步：

```bash
git clone https://github.com/Glittering/ai-browser
cd ai-browser && npm install
```

注册进 Agent 的 `.mcp.json` 就行，**浏览器自己会启动、自己会关闭**，不用你管。

## 💬 实测过什么场子？

知乎文章全流程、CSDN 发布、百度搜索、东方财富查询、同花顺、魔塔……都能跑。
