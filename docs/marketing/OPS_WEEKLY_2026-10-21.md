## 三、五个关键判断

### 1. 掘金：话题挂载 = 流量开关（已验证），CTR = 新瓶颈
- 证据：同账号、同为原理向长文，挂话题的 1264 展现 vs 没挂的 8 展现，**相差 158 倍**。
- 新瓶颈：31/1264 = 2.5% CTR。掘金信息流同类热文 CTR 普遍 5%+。下一篇标题必须 20–30 字、带数字、封面带信息量；发布后 30 分钟内在评论区自补一条（新号初始互动直接影响推荐量）。
- 可达性锚点：掘金 AI 类目热榜 #15 是 476 阅读。以当前分发量，**进入热榜 = 单篇 500+ 阅读是可达目标**。

### 2. CSDN：搜索流量 + 高收藏率 = 当前最高效资产
- 文章2 的 21 收藏 / 184 阅读（11.4%）说明内容切中了真实痛点；文章1 五天 261→297 证明长尾在复利。
- 打法不变：标题含真实搜索词（"Playwright MCP 替代方案""Agent 操作网页 不用截图""Draft.js 自动化粘贴"这类），结构 = 小标题 + 目录 + 代码块 + FAQ + 小结。**每周 1 篇，断了就前功尽弃。**

### 3. 知乎：不是渠道问题，是落点问题
- 上一答 0 赞的真因：问题本身只有 429 浏览 / 7 关注（低于 playbook 20–200 线），不是内容问题——同题材竞品原理向回答能拿 35–161 赞。
- 下次严格执行：创作中心 → 等你来答，只挑**关注者 ≥20、回答数 <15、近 30 天有新回答**的问题；发布时附"可复现最小步骤"。

### 4. 转化链断裂是全盘第一矛盾
- 8 篇内容 ~760 阅读，referrers 0。读者看完没有下一步动作。
- 三个改动：① 所有新稿的 CTA 从"文末裸链"改为"文中给一条命令 + 一个立刻能做的任务"；② 掘金/知乎简介区放仓库链接；③ GitHub Discussions 搭台（自问自答 3 条，草稿见第五节），让"跑不通来提问"有地方去。

### 5. npm 410 的归因未定，先观察不庆祝
- 时间点与 2.1.0「一条命令就能用」强相关，且 10-20 起持平——符合发布脉冲特征。若一周内周下载跌回 <100，说明是版本更新噪音；若稳在 300+，才是真实采用。**北极星指标维持"周新增真实安装"，下周同一时间复核。**
