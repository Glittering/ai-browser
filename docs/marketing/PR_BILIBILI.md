## 分 P 口播脚本

### 【开场 0:00】

今天给大家看一个有点炸的东西。我的 AI 助手，居然自己把知乎一篇文章写完、排好版、还点开了发布框。

### 【痛点 0:30】

之前它可不是这样。让它操作网页，不是卡登录，就是读不懂弹窗，富文本编辑器更是一进就死。为什么？因为主流做法是——**截图 + 猜**。截图给 AI 看，AI 猜位置去点，网页一动全废。

### 【转折 1:00】

我找到了一个反着来的项目，叫 **AI Browser**。它不截图，直接把网页结构读成"语义树"给 AI。AI 拿到的是带编号带类型的接口，点哪里、填什么，清清楚楚。

### 【演示 1:30】

（放实操画面）看，这是知乎的编辑器——利用 Draft.js 全流程，标题、多段落、加粗、清空、发布，全过了。这是所有截图方案都搞不定的地方，它轻轻松松。

### 【原理 2:30】

为什么能过？因为点按不是程序模拟，是走浏览器底层的**受信键鼠事件**，跟真人操作一个级别。所以 Draft、ProseMirror、Quill、CKEditor，不管啥编辑器，**一套通吃**，不用单独适配。

### 【安装 3:00】

装只要 3 步：git clone，npm install，注册进 Agent 的 `.mcp.json`。浏览器自己会起、自己会关，全托管。

### 【结尾 3:30】

地址放这了：`github.com/Glittering/ai-browser`。**Star 不多，但绝对是宝藏项目**。用得好记得点个星，让更多人看到这种真正能打的 Agent 工具。下期见！

- MIT 开源，主仓库：https://github.com/Glittering/ai-browser

- 实测站点：知乎（Draft.js 全流程）、CSDN（发布）、百度、东方财富（2458 节点）、同花顺、魔塔
