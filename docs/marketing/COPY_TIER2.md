## 1. 简书（随笔向 · 约 1200 字 · 需投稿进专题）

**标题：**《我不再让 AI 看截图了》

**正文：**

```
有段时间我一直觉得是自己不会用。

让 AI 去知乎发篇文章，它卡在登录页；让它去后台点发布，它读不懂弹窗；让它读个金融网站，它只会不停截图，然后告诉我"我看到了一些内容"。

后来我想明白一件事：它不是不聪明，它是瞎的。

我们给它的不是一个网页，而是一张图。网页明明是一棵树——标题是标题、按钮是按钮、输入框有名字、有状态、能点能填。可一截图，这棵树就变成了像素矩阵，所有结构信息全没了。然后我们还指望它从像素里"认出"哪个是按钮，再猜一个坐标去点。

于是就有了那些经典的翻车：页面滚一下坐标全废；toast 提示"发布成功"一秒钟就没了，截图根本来不及；Draft.js、ProseMirror 这种富文本编辑器，光标都进不去。

更别说 canvas。canvas 上压根没有 DOM 节点，基于 accessibility tree 的方案在这里拿到的是空的。

所以我换了个思路：别让 AI 看像素，让它看结构。

我把页面转成语义树——每个元素带上角色、标签、值、状态、可执行动作，外加一个稳定 ID。Agent 拿到的不是图，是这样的东西：

{
  "role": "textbox",
  "label": "请输入文章标题（5～100 个字）",
  "value": "AI Browser 测试标题",
  "states": ["visible", "focused"],
  "actions": ["type", "clear", "focus"]
}

顺便把弹窗、必填提示、成功消息、登录态一起塞进 context。

输入也有讲究：不能用合成 JS 事件，得走 CDP 的受信键鼠事件。这条通道通了之后，Draft.js、ProseMirror、Quill、CKEditor 全都不用单独适配——因为它们本来就是给真人的键鼠用的。

然后我还加了一条：每个动作必须返回"它到底改变了什么"。

这是被坑出来的。有次工具返回 success，但页面上什么都没发生，Agent 信了，继续往下走，等第三步的时候错误已经被放大到看不出原样了。所以我把"验证"做成了工具原语：快照前后对比，返回显式的 changed/unchanged 判定，带上前后值和路径，再对页面数据模型做个指纹。这样连"只改 canvas 数据、DOM 零变动"的操作也能抓住。

现在它可以干这些事：用你已登录的浏览器去后台发文；在 canvas 白板上写字，再不靠 OCR 把自己写的字读回来；遇到扫码和滑块时，你伸手拿鼠标接管，它就在对话里等着。

最后说清楚边界：目前只在 macOS 和 Linux 上测过，Windows 没测；首次启动要拉约 110MB 的引擎数据；控制端口只绑在本机，而且没有鉴权——别把它转发出去。

项目在这里，MIT：https://github.com/Glittering/ai-browser
想试就一条命令：npx -y @glittering0717/ai-browser mcp
跑不通别急着关，把日志贴到 Discussions，那才是我最想要的输入。
```

## 2. OSChina（开源语境 · 约 1300 字）

**标题：**《给 Agent 的浏览器为什么要"可见"：一个 Electron + MCP 的实现》

**正文要点（写成正文）：**
1. 先把结论说清楚：我要的不是一个无头浏览器，而是一个**我也能看见、也能插手的浏览器**。
2. 为什么：Agent 自动化真正的断点从来不是"不会点"，而是**身份**——登录态、扫码、2FA、滑块、支付确认。这些环节人类必须在回路里，但又要能随时接手。
3. 现有做法的问题：临时实例每次都是新的，登录态不共享；复制 profile 的做法会遇到并发占用和版本冲突。
4. 我的形态：Electron 常驻窗口 + 两套等价接口（MCP stdio 20 个 `browse_*` 工具 / WebSocket JSON-RPC `ws://localhost:9223` 的 `ui.*` 方法）。
5. 感知：语义树，不是截图。含 context（弹窗、必填、成功消息、登录态）。
6. 输入：CDP 受信事件，富文本编辑器零适配。
7. canvas：从 `fillText()` 绘制调用层直接取字符串，零 OCR（需要 `AI_BROWSER_CANVAS_HOOK=1`）。
8. 验证：`browse_diff` 显式 changed/unchanged。
9. 边界：macOS/Linux 已测、Windows 未测；端口只绑 localhost 且无鉴权。
10. 开源信息：MIT、仓库链接、欢迎 issue/PR。

**同步发「动弹」**（100 字内）：
> 用 Electron 做了个给 Agent 当驾驶员的浏览器：读页面语义树，不走截图不 OCR，人随时能接管鼠标。MIT 开源：https://github.com/Glittering/ai-browser
