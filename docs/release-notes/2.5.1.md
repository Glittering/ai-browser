## 找不到第二个"说明的"了，于是换了个办法找

之前所有"参数传了不报错、但什么都不做"的洞，都是靠读代码一行行对出来的。这次我把
`PageManager` **真的构造起来**跑了（`tests/test_page_manager.js`，7 条），第一分钟就抓到：

**`this._preloadPath` 只在 `index.js` 里赋值，`page_manager.js` 自己从不初始化。**
`preload: undefined` 不报任何错 —— 症状只是"每一条读树都超时"，而所有错误信息里没有一个
字指向 preload。现在构造函数里有默认值，`newTab` 里做一次性自检并落盘 `preload_missing`。

（这也是审计 C12 的正面回答：`tests/` 里此前**从来没有构造过真的 PageManager**，
`makePageManager()` 全是手写对象字面量。）

## 这一版改了什么

**① 三处还是会"静默空转"的参数**
- `subset` 传 `'all'`（`wrapper_hint` 自己建议过的值）或任意拼错 → 以前**静默返回全量**，
  调用方以为省了 token。现在 `-32602` 并列出合法值。`mode` 同理（`diff`/`full`）。
- `ui.wait` 的 `button_enabled` 不传 `target`、`text_*` 不传 `text` → 以前跑满 timeout 才回
  `satisfied:false`，读起来像"条件没出现"，实际是"你少传了一个参数"。现在立刻 `-32602`。

**② 退出不再白等 2 秒**

`persistSessionCookies` 以前靠"固定睡 2 秒"碰运气（注释里记着实测：86 个 `cookies.set()`
全部 resolve，磁盘只剩 2 个）。改用 `session.cookies.flushStore()` —— 它就是为这件事存在的
原语：强制写盘并等它完成。拿不到这个 API 时才退回原来的等待。

**③ OS 级沙箱变成可选**

`--no-sandbox` 以前是硬编码（受限 shell 里 sandbox helper 拿不到权限，不加就起不来）。
现在 `AI_BROWSER_SANDBOX=1` 就不加这个开关。默认仍然关 —— 这是权衡（"装上打不开"比
"少了纵深防御"更急），但不再是没法选。

**④ 语法闸门**

`src/` + `bin/` 每个文件过一遍 `node --check`（`tests/test_syntax.js`，2 秒）。它覆盖的是
单测**永远碰不到**的那部分：`src/main/index.js` 只能由 Electron 加载，里面写错一个括号，
应用起不来而 CI 全绿。
