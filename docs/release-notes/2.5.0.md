# v2.5.0 — 安全：堵死「页面 → 宿主」与「页面 → 控制面」两条链

这一版是安全版。起因是复核另一会话的审计时，我把那两条链**在真机上跑通了**，
而不是"理论上可能"。

## 两条链，都实测过

**链 A：任何网页 → 宿主代码执行。** 一个普通 `http://` 页面里 `new WebSocket('ws://127.0.0.1:9223')`
就能连上控制面，`ui.list_tabs` 枚举出全部标签页，`ui.evaluate` 读到**另一个源**的正文。
再一条 evaluate：

```js
Function('return globalThis["pro"+"cess"].version+" / pid="+globalThis["pro"+"cess"].pid')()
→ "v20.18.3 / pid=40158"
```

拿到的不是页面里的 `process`，是**主进程那侧的 Node**。机制不是"CDP 不可用时才降级"这么温和：
`evaluate` 的 catch 把**页面脚本自己抛的异常**也当成"CDP 不可用"，于是任何会抛错的表达式都会被
拿到 preload（有 Node）重跑一次；而 `guards.js` 只挡字面量 `process.` / `require(`，拆词拼接即可绕过。

**链 B：任何网页 → 伪造 agent 看到的东西。** `preload` 通过 contextBridge 把 `sendTree` / `sendDiff`
暴露给页面主世界，主进程 `ai:tree` 只按 `payload.id` 认领 pending，而 requestId 是 `++` 自增。
页面循环 id=1..N 就能撞上在途的 `getTree`，喂一棵假树（把"确认支付"换成"取消"这类）。这条路
**不需要 WS**，所以它和链 A 是两个独立入口。

## 改了什么

**1. WS 握手见 `Origin` 即拒（1008）**

浏览器在 WebSocket 握手时必发 `Origin`；Node 客户端（`ws` 包、Node 全局 `WebSocket` —— CLI / MCP /
e2e 都用这两种）**不发**（两种都实测过）。所以这条判据很硬，且不误伤任何正常客户端。
`AI_BROWSER_WS_ALLOW_ORIGIN=1` 是调试/阳性对照用的逃生门，默认关。

**2. 删掉 preload 的 `eval`**

`ai:evaluate` 通道与 `_evaluateViaPreload` 一起删除。evaluate 只剩 CDP（页面主世界，无 Node）；
失败**分类后如实上报**（`cdp-unavailable` / `cdp-timeout` / `script-error`），不再有"安全地降级"
这种选项 —— 那条路上有 Node，不存在安全的降级。

顺带修掉了根因：**页面抛错不再被当成"环境不可用"**。此前一个正常写错的表达式会被报成
`cdp-unavailable`，调用方于是无限重试；现在如实说"你的脚本抛了错"。

**3. 删 `sendTree` / `sendDiff`，`ai:*` 一律校验 sender + tab + kind**

`shared/ipc_guard.cjs` 是唯一判据（纯函数，表驱动单测）。`ai:diff` 通道一并删除（它唯一的产出者
就是 `sendDiff`）。`ai:event` 也必须带得出发起 tab，归属不明的事件不再广播。

**4. upload 加路径闸门**

`upload` 能把本机任意文件塞进站点，是"读本地文件"的原语。现在：必须绝对路径、必须存在且是普通文件、
**realpath 后**再判敏感位置（`~/.ssh`、`~/.aws`、`.env`、私钥扩展名、浏览器 Cookies…）、大小上限
512MB。`ln -s` 指向私钥也拦（先 realpath 再匹配 —— 第一版忘了这一步，被自己的用例抓出来）。
`AI_BROWSER_UPLOAD_ALLOW_SENSITIVE=1` 只给"我确实要传私钥"的本机开发者，打开时回执标
`sensitive_override`。

## 顺手修掉的"声明 ≠ 实现"

这些参数的共同点是**传了不报错、但什么都不做**，比报错更贵：

| 参数 | 之前 | 现在 |
|---|---|---|
| `subset:'interactive'` | 只在 `ax:true` 分支生效，默认读法静默忽略 | 默认读法也剪枝（复用同一 `filterInteractive`，两条读法形状一致） |
| `focused_only` | 参数传到 preload，抽取器压根不读 | 真裁剪：祖先链 + 焦点子树，根带 `focused_element_id`；无焦点时明确说"没有焦点"而不是返回空树 |
| `mode:'diff'` 不带 `ax` | 静默返回整棵树 | 明确 `-32602`：`mode is only supported with ax:true` |
| `ui.wait` 未知 condition | 白等到 timeout 回 `satisfied:false` | 立刻 `-32602` 并列出合法值 |
| `ui.wait` text/url 条件 | 每轮先抽整棵树再丢弃 | 只调 `evaluate`（树只给 `button_enabled` / `modal_appeared` 用） |
| `focused_only` 的拼写 | raw WS 是 camel、MCP 是 snake，抄错就空转 | 两种拼写都认 |
| MCP 传输超时 | 固定 15s，把 `wait` 60s / `act` 120s 腰斩 | 按工具预算算（`shared/tool_timeout.js`），其余工具仍 15s |
| `ui.paint_check` | 绕过路由直接打 `activeTab`（`heal:true` 会重载**人正在看的**那页） | 走统一目标路由 |
| 解析错误回执 | 缺 `id:null` | 补上（JSON-RPC 2.0） |
| `screenshot` 回执 | 把路由参数 `tab` 报成 `ignored_params` | 不再误报 |
| `wrapper_hint` | 建议 `subset:"all"`（schema 里没有这个值） | 建议 `"full"`，且测试从 schema 取枚举断言 |

## 健壮性与清理

- `_ensureCdp` 不再"发出 enable 就算启用"：记账可撤销（失败删除 + 落盘 `cdp_enable_failed`），否则
  一个没启用的域会永久以"看起来可用"的姿态失败。
- `tabsInGroup` 的 `webContents` 裸解引用改成 `isAlive()` —— 正是白屏事故那一类写法。
- 视图布局公式从两份收敛成 `_viewBounds()` 一份（历史上就是漏改一处导致 inset 丢）。
- 下载同名不再覆盖：`report.csv` → `report (1).csv`（Electron `setSavePath` 会直接覆盖）。
- 删除 `src/shared/protocol.js`：只被它自己的单测引用，生产从未用它校验 —— 一个"看起来在校验"的
  死抽象。相关文档同步。
- `test_imports` 新增 `.cjs` 可加载闸门（此前 preload/shared 的 CommonJS 模块**没有任何静态检查**：
  语法错或空导出要等真机才炸）。
- README 订正：工具数 20→17、工具表补 3 行、badge 658+447→1309+831、"src 里没有任何截图调用"
  （与 `Page.captureScreenshot` 矛盾）改成"读页面不经过截图，截图只是诊断"。

## 破坏性

- 浏览器发起的 WS 连接（`Origin` 非空）会被拒。本仓库内没有任何这种调用方；若你有自研的
  web 面板通过浏览器连 9223，需要改成经本地进程代理，或显式设置 `AI_BROWSER_WS_ALLOW_ORIGIN=1`
  （不建议）。
- preload 不再暴露 `sendTree` / `sendDiff`（生产无调用方）。
- 仍未做：**启动 token**（`docs/PLAN_REMEDIATION.md` 的 SEC-01 后半）。理由写在
  `docs/AUDIT-VERIFY-2026-10-31.md`：Origin 判据已经挡住"页面"这条真实路径；token 保护的是
  "本机已有代码执行权的进程"，收益小、迁移面大（CLI/MCP/e2e 全要改）。要做得单独一轮。
