# v2.4.2

一个假阴性：**「window 上没有模型」被当成了「没有模型」**。

## 修的是什么

`ui.capabilities` 扫 `window` 上的对象给出选路。两次实测里，它把
`draw.yunser.com` 和 `suxieban.com` 都报成 `no app object on window`，
agent 据此降级到 L3 指针手势 + 帧指纹 —— 而这**两个站都不是那样**：

- **suxieban 是 fabric 5.2.1**：`getObjects()` / `toJSON()` / `toSVG()` /
  `loadFromJSON()` 全在，完整矢量模型。
- **yunser 有 `window.DrawBoard`**：`getState` / `loadState` / `save` /
  `getDataUrl` 全在（它是位图层，但"完整位图快照"和"什么都没有"是两件事）。

判错的不是站点，是找法：**实例关在闭包里**，`window` 上只留了库本身或构造器。
扫 window 永远扫不到。

## 加了什么

`browse_capabilities { deep: true }`（WS：`ui.capabilities` 同参数，另有独立的
`ui.app_model`）：

1. **按库指纹认库**，不靠猜 window 上的名字：fabric（`lower-canvas` +
   `fabric.Canvas`）、Konva（`Konva.stages`）、paper（`paper.projects`）、
   Excalidraw（`window.excalidraw.$excalidraw`）、CodeMirror（`.CodeMirror`
   宿主属性）、Monaco（`monaco.editor.getModels()`）。
2. **实例在闭包里的那些**：在原型方法上挂一个只记 `this` 的 tee，
   `Reflect.apply` 原样转发 —— 参数、返回值、异常、`this` 一律不变。
   再派发**一条**合成 mousemove，让页面自己的代码走一趟，实例就回来了。
   ⚠️ fabric 5 的事件入口是**双下划线**的 `__onMouseMove`，只 hook
   `_onMouseMove` 实测完全抓不到。
3. **每个库一个 `read(list)`**，只调 getter，返回统一的
   `{type, x, y, w, h, text, fill}` 加 `supports`。**`supports` 是对实例逐个
   `typeof` 实测出来的**，不是硬编码清单 —— 广告了却不存在的能力比不广告更坏。

返回里的 `read_expr` 可以直接喂 `ui.evaluate`：它只在**当前文档**有效，
导航后返回 `null`（不是抛错，可判断）。

命中后推荐路线改为 `L1_app_object_model`，并把其他并列首选降级 ——
实测 suxieban 上曾出现 `["L1_app_object_model","L2_semantic_tree"]` 两个并列首选。

## 实测

真 Electron + 真 Chromium：

- **suxieban**：空板 `count=0` → 加一个 160×100 矩形 → `count=1`，
  回读 `{type:'rect', x:200, y:150, w:160, h:100, fill:'#22c55e'}` → 删除 → `count=0`。
- **迅捷白板（Excalidraw）**：`excalidraw acquired`，
  推荐从 `L2_semantic_tree` 改为 `L1_app_object_model`。
- **yunser**：如实报 `no known library matched`，并给出两条可执行下一步
  （先找导出入口；再手写 tee），不假装成功。

## 明确的边界

- **合成 mousemove 是"打扰页面"**。返回里用 `side_effect` 如实说明派发了几条，
  不假装读取零副作用。
- **钩子活在当前文档里**，导航即失效（`stale_after_navigation: true`）。
  `window.__aiAppModel.restore()` 会把原型方法原样还回去 —— 此前这里写着
  `delete window.__aiAppModel`，那只是丢掉账本、tee 还挂在原型上。
- 读得到的是**结构**，不是"这张图长什么样"。

## 判据

- 单测 `tests/test_app_model.js` 23 条：读取器归一、几何（含 scale）、
  `supports` 实测、探针在 jsdom 的**同构页面**上真抓到实例、幂等、自愈、
  restore 真还原、expr 类不碰原型、`read_expr` 真求值。
- e2e `npm run appmodel` 16 条，已进 `e2e:all`（23 套件）。
  jsdom 的 `getBoundingClientRect` 恒 0、没有真实事件链路 ——
  "派发一条合成 mousemove 就能走到 tee"这个假设在那里是被 mock 兜住的，
  只有真浏览器能证伪它。
- API 预算从 17,000 B 调到 17,200 B（实际 17,131），理由写在
  `tests/test_api_budget.js` 的历史里：没有加工具、没有新增顶层参数。
