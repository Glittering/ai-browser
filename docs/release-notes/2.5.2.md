# v2.5.1 → v2.5.2 — 文档：把「沙箱默认关闭」这件事写清楚

只有文档改动，没有运行时代码变化。起因是一次实测：

```
AI_BROWSER_SANDBOX=0 → ALIVE，监听 127.0.0.1:9464
AI_BROWSER_SANDBOX=1 → DIED，日志 "sandbox initialization failed: Operation not permitted"
```

（源码版 Electron 与打包版 `/Applications/AI Browser.app` 表现一致。）

这说明 `--no-sandbox` 在受限 shell 里不是"懒得开"，而是**开了根本起不来**。但这个失败发生在
我们的 JS 跑起来之前 —— 所以程序自己来不及写日志、弹横幅、落盘错误，用户只能看到一个静默退出。

README（英文 + 中文）现在写明三件事：

1. 沙箱**默认关闭是有意的**，原因是受限 shell 里 Chromium 的 sandbox 起不来；
2. `AI_BROWSER_SANDBOX=1` 可以打开它；
3. **打开后启动即退、一点输出都没有，就是这个原因** —— 去掉变量即可。

顺带在中英文 README 里各补一句：握手带 `Origin` 的连接会被拒（这是 v2.5.0 的安全边界，
浏览器必发、脚本不发），中文版此前没写。
